# Bitácora técnica

Todo lo que averigüemos del juego se apunta aquí: una sola fuente de verdad para los tres.

## Build de referencia

**Todas las direcciones del proyecto valen solo para este ELF.**

| Campo | Valor |
|---|---|
| Serial | _pendiente_ (USA: SCUS-97399) |
| ELF | _pendiente_ (USA: `SCUS_973.99`) |
| SHA1 del ELF | _pendiente: lo imprime `extract-iso.ps1`_ |
| Entry point | _pendiente_ |
| CRC32 del ELF | _pendiente_ |
